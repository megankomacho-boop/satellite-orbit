# 人工衛星の軌道アニメーション（日本の衛星）

Google Colab上で、人工衛星の軌道を地図や地球儀の上にアニメーション表示するプログラムです。
衛星の種類と再生速度（10〜1000倍）を、画面のボタンで切り替えられます。

## 主な機能
- 衛星の選択（だいち2号、いぶき2号、ひまわり9号、ISSなど）
- 再生速度の切り替え（10・100・200・500・1000倍）
- 平面地図版と地球儀版

## 使い方
1. Google Colabで新しいノートブックを開く
2. プログラムをセルに貼り付けて実行する
3. 下のドロップダウンで衛星を選び、速度ボタンで再生する

## 使用ライブラリ
- [skyfield](https://rhodesmill.org/skyfield/)：軌道計算
- [plotly](https://plotly.com/python/)：地図の描画とアニメーション

## データの出典
- 軌道データ（TLE）は [CelesTrak](https://celestrak.org/) から、実行時に取得します（データ自体はこのリポジトリに含みません）。
- CelesTrakの利用ポリシーに従い、短時間に大量のリクエストを送らないでください。

## 注意
- 教育・参考用です。位置の正確さは保証しません。
- 位置の精度は、軌道データ（TLE）の新しさに左右されます。
- 表示は予測で、リアルタイムの位置ではありません。
